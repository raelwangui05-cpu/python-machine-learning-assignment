 THEORY QUESTIONS ANSWERS 
1.Supervised machine learning is a type of machine learning that trains the model using labelled datasets for classification and prediction of outcomes. 
2.Unsupervised machine learning is the type of machine learning where algorithms learn patterns from unlabeled data ,commonly using clustering ,assosiation rules and dimensionality reduction techniques such as K-Means.
3.Supervised machine learning uses labeled data to train the model while unsupervised machine learning uses unlabeled data to train a model. 
  Supervised machine learning focuses on precise prediction and classification while unsupervised machine learning focuses on pattern recognition.
4.Linear Regression is considered supervised machine learning since it trains on labelled data,input features on x axis and the target values on the y axis. 
5.KMeans is considered unsupervised learning since points out data with similar features and groups them together without predefined targets.
6.fit() trains a model by calculating its optimal parameters from training data while predict() uses the learned parameters to generate output for new and unseen data.
7. Supervised learning: a)Spam detection to intercept junk mails. b)Fraud detection in financial platforms such as banks.
 Unsupervised learning:a)Customer segmentation b)Biology and genetics to discover evolutionary relationships.
